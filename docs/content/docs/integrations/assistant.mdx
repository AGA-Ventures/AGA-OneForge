## Slack

Connect **Slack** over **OAuth** to put the **AGA OneForge Assistant** in your workspace and receive
**<Term id="nonconformance">nonconformance</Term> notifications** where your team already talks. There are no fields to fill in.

<Steps>
  <Step>
  ### Start the Slack install

  Authorizing opens a Slack install popup.
  </Step>
  <Step>
  ### Choose your workspace

  Pick the workspace to install into and approve the install. AGA OneForge stores the connection. No keys to paste.
  </Step>
</Steps>

| Setting | What it controls |
| --- | --- |
| Connection | Established by the Slack OAuth install — no keys to paste. |

<Callout type="warn">
Slack is **hidden in controlled (ITAR) environments** — when AGA OneForge runs in a controlled deployment, the
Slack integration doesn't appear at all.
</Callout>
